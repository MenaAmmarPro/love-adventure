# Adventure Machine — love-adventure

Spin a little co-op quest for two: **where** to go, **what** to do, and one
silly **twist**. Reels can be locked; a quest link (`?q=w,wh,t`) carries the
exact same spin to the other half of the couple. Finished quests go in a
local logbook.

Live: https://menaammarpro.github.io/love-adventure/

## Storage key

- `mena-adventure` — `{ spins, done:[{w,wh,t,text,at}], locks:{where,what,twist}, current:{w,wh,t} }`
